## 契约与实现

- 原任务来源：03 T43 / T13 / T14，01 §6.3 / §8.4–8.5，02 §2 / §6，04 DS 稳定组件，05 R01–R12。
- 自动提案仅来自已成功提交的正式会话 FULL_ANALYSIS；演示、临时、改写及摘要不询问或写入。每次完成最多选择一条合法且尚未记住的提案，作为低可信度的军师猜测；模型无权升级事实来源，subject 固定当前 owner，防止随机 subject 绕过五条配额。
- 同意卡精确披露本机与模型发送范围，两按钮复用同权 ConsentCard；拒绝保存非敏感时间戳，30 天不再询问，可主动开启。接受卡以原 generation / consent / source / owner / memory revision 做 CAS 授权，随后用批准后 stamp 写入；未知或失败不显示已记住。
- owner 的 MEMORY_STATE 保存在加密 owned_records 中，无 DDL 改动。WriteStamp 增加默认 nullable memoryRevision，仅记忆 Repo 检查；风格授权不受无关联系人的记忆编辑影响。编辑/删除/标错/撤销仅推进 owner revision 并清 owner SUMMARY；全局暂停、恢复、撤回才改变 consentVersion。仅记忆清空逐 owner 推进版本，保留联系人/聊天/风格/同意。首页 inline 与管理 route 分离，MemoryDisplayCoordinator 独立处理 route epoch / notice 寿命，防止 A 管理页与 B 流串状态。
- 标错保存 owner 隔离的 NFKC / 大小写 / 空白规范化 SHA-256 内容指纹，拒绝随机 ID 再写；不在明文偏好、日志或数据库 payload 中保留标错原文。模型 mask 在持久化时按来源 request 哈希 namespace，防止跨轮 [昵称1] / [手机号1] 碰撞；标错规范化剥离 namespace 后仍拦截同内容。标错后清操作历史，不能撤销把已标错内容复活。
- 稳定 USER / OBJECT / RELATIONSHIP 继续拒绝超额，原 Python 事件/假设通用规则保持；自动 ASSISTANT_INFERENCE / LOW 使用来源、可信度、时间排序淘汰最低优先项。高可信人工记录优先保留，候选本身优先级最低时拒绝，不显示成功提示。生产自动写入必须核实实际 COMPLETED / BYOK run、用户消息、联系人与已确认证据；MEMORY_SOURCE 仅存用户/证据/已选旧记忆依赖 hash receipt，删除/修改来源或旧记忆后固定点剪除派生记忆并清 undo，独立人工资料与其他 owner 不受影响。新增 MemoryContextPolicy（纯 domain）共享 canonical 条目receipt、依赖摘要和只读保留权限。重复同值提案拒绝，不更新来源、不增revision、不提示写入。

配额与来源依赖决策（父任务已裁决）：自动 HYPOTHESIS 容量逐出允许保留 owner 隔离、无原值且不可逆的来源 hash 锚，以证明仍获准后代的来路。锚不作为 active 记忆、模型 input 或事实来源，不携同意；HTTP 仍严格当前 memoryRevision。复制/history 可凭仍有效锚验证旧 snapshot，不伪造原请求。用户主动删/改/标错、原 user/line/run 删除或改变会撤销锚并固定点剪除后代；暂停后 context 为空；仅记忆清空和撤回均删除锚/source receipt/undo。锚的 GC 根仅为 active 条目与最近 20 操作中的实际条目，不让锚快照自身成为 GC 根；按来源依赖闭包保留，owner 最多 200 个锚及 400 份 source receipt。单锚仅 ID≤128 和两个 SHA-256；单 source receipt 的 run/conversation/line ID≤128、line≤512、依赖≤200，全部仅 ID/hash，不复制 request/chat 原文。超过上限事务拒绝，已有隐私围栏不被删除，答案保留且诚实提示此次没记住。
- 联系人记忆管理入口使用独立 MemoryScreen，按五组显示来源/可信度/本机更新时间，复用 MemoryEntryRow，编辑只在 remember RAM。新增“添加一条由你确认的记忆”：用户必须主动选择五组之一，再按“由我确认并保存到本机”；只有该明确动作建立 USER_EXPLICIT，默认无分组。普通编辑保留原来源与保守可信度；暂停期间仍可删除/标错，全清不要求恢复，新增/编辑/恢复撤销仍按原持久化同意规则。
- MemoryChangeNotice 协程 8 秒收起，保留最新操作入口；时间等待可注入。临时/路由/版本/锁变更清敏感编辑与提案。删除、仅记忆清空、撤回和全部数据清除分别披露后果。
- actualDataContext 冻结当前 owner 的 active 记忆及 consentVersion / memoryRevision 围栏，并明确推测不是事实；沿用 canonical PromptBuilder → Redactor → 实际 HTTP / preview 管线，无新增 AnalysisRequest 序列化字段，也不发送 Contact.notes。网络与写入要求完整 revision 相同；复制和连续 history 使用内嵌 typed JSON 条目 receipt 的不可变子集核验，因此新增记忆不清空刚完成的答案，也不伪造旧 request。编辑/删除/暂停使旧依赖失效；恢复、历史答案动作、预览和网络启动再次验证；删除/撤回立即撤销当前 owner 的冻结预览、恢复和原答案操作权限。
