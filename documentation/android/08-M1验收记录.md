## 设备完整流程

在独立 Android 15 / API 35 AOSP x86_64 实例进行，WHPX、2 核、2 GiB，未安装 Google Play services：

1. 安装并冷启动成功。
2. 仅创建合成联系人 `synthetic_m1_contact`，快速输入 `synthetic_m1_saved_draft`，核对内容精确且不乱序。
3. 实际通过知识打包校验、演示生成和原生复制；force-stop 后启动新进程，正式草稿精确恢复。
4. 在临时问问输入另一合成标记，终止进程；重启只恢复正式草稿，临时标记消失。
5. 仅删除上述合成联系人，未清除其他应用或用户资料。

已加入 `scripts/smoke_android_m1.py`，在安装前用 aapt2 校验唯一 debug 包和 debuggable 标记；已有三个允许／拒绝回归。脚本从 stdout 读取 UI 树，不写共享存储，只用于空白专用模拟器。完整运行已得到 5 项 PASS，CI 在 T16 增量接入。

此项不代替三品牌真机、TalkBack、最高系统字号、OCR 性能及真实模型验证。
