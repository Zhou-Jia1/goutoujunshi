# T42 联系人档案与时间线

状态：本地实现、独立规格/质量复审、分轮JVM/截图/构建及原生M1验证通过；扩展导入/设置设备回归通过。T43完整记忆管理、T41完整风格页、T52完整对练仍为后续工作包；本包不把预留能力记为完成。

联系人列表使用职场、亲密、家庭、社交四组；16种关系全部映射，调解在社交列表内保留“调解双方”标签，领域 MEDIATION 与知识路由不变。卡片打开档案详情，删除在详情中操作。归档资料仍加密保留，可从已归档列表恢复；普通选择、默认启动及导入候选排除归档联系人。恢复后旧分析仍失效，需要主动重新分析。

档案只要求代号与关系，手工资料可选（代号80、资料4000 UTF-16单元上限）。资料来源明确标为用户主动填写，仅保存本机加密Contact payload，不进入请求contactContext，不自动开启记忆/风格学习。未来若将它用于模型背景，必须另接既有真实出站范围、统一脱敏、冻结实际HTTP预览与用户确认；本包不暗中添加该背景。

详情有概览、时间线、档案、记忆。概览只显示来源仍有效的最近模型建议，并把用户主动记录的发送/修改后发送/未发送与模型建议分开。跟进不推测对方是否已经回复，行动不自动作为学习样本。统一 typed 时间线按真实时间跨类型排序：导入时间来自ChatImport.importedAt，分析时间来自Message.createdAt（本机收到Completed并通过AnswerPolicy后的完成时间），关键事件来自Event.occurredAt和timePrecision；ActionPlan没有行动时间，不借用分析/加载/当前时间，未记录时间的项放末尾并明确标注。界面不显示机器ID。过期分析保留记录，正文不作为当前证据。

导入来源展示复用FactSourceResolver，限定当前owner、当前来源版本和当前确认消息。不按昵称猜身份、不回查他人。旧Event没有可验证的来源版本，当前只显示事件记录并标为来源不可用，不把它的lineRefs当成当前事实。记忆只读展示已有记录的用户明确提供/用户转述/工具导入/助手推测来源、置信度与停用状态，不把AI提案当成用户主动资料或默认同意。

“和军师聊聊TA”通过同一CounselRuntime/CounselController显式选择该联系人并跳转现有军师页，沿原知识与发送预览链；不会把临时问问无确认转存。“对练”打开明确的未开放说明，不调用模型、不假装成功。T52需要在此入口接入完整功能和相同出站门禁。
