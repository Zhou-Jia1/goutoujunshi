## 生产行为

- 此刻心情沿用可选 0–10 分输入，不打分可使用；请求使用当前分数，不增加情绪档案或统计事件。
- 同一缓存分类器读取 `calm-keywords.txt` 和 `crisis-keywords.txt`，缓存解析成功或加载失败。输入、导入证据、预览和普通发送复用 Controller 的本地门禁；危机先于模型出现安全卡，失败时关闭普通建议并提示本地资源不可用。
- 情绪 ≥8、本地高情绪或模型 CAUTION 使用同一 `SafetyPolicy`，App 与悬浮主题都真实切换。App 先展示承接和一件小事，其余折叠；展开后的回复前有“先别急着发”和明确十分钟草稿操作。

- 复制、保存草稿、收卡携带完整答案/输入/来源/规则/配置 stamp、epoch、lock generation；挂起保存返回后重检同一凭据。旧回调不能获取新答案权限。剪贴板继续标记为敏感内容，不额外读取。
- CRISIS 立即停止普通展示、移除对练与教学、撤销旧复制界面；流中最高安全级别写入现有 run checkpoint，普通结果不能降低。用户确认安全仅收起卡片，保留“安全帮助”入口，统一最高安全门禁继续关闭普通内容。
