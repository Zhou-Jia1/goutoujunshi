# 02 · 人性化体验规范

> 2026-10-31 修订：适配「全场景聊天军师」。新增第 12–16 节（导入、风格、教学、场景差异、悬浮军师），并调整了第 2、4、6、7、8 节。

「人性化」在这个产品里不是加几句暖心文案，而是一组**可验收的行为规则**。用户打开这个 App 时，往往是领导的消息不知道怎么回、和家人又吵起来了、暧昧对象突然冷淡：注意力差，可能正在工位上或者旁边有人，对方可能正在等回复。用户的另一个共同点是**觉得自己不会聊天**，所以产品既要帮用户解决眼前的问题，也不能让他觉得自己很笨。所有设计都要围绕这些状态来做。

每条规则都标注了实现要求（→）。Codex 实现时以 → 后面的内容为准。

## 1. 七条体验原则

| # | 原则 | 含义 |
| --- | --- | --- |
| 1 | **先帮忙，再认识** | 不登录、不填问卷就能问；档案在对话中慢慢补齐 |
| 2 | **先接住，再分析** | 情绪强烈时，界面本身要变得更安静，而不只是文字变温柔 |
| 3 | **答案先行** | 用户最想要的东西（一句回复、一个结论）永远在第一屏 |
| 4 | **用户永远有退路** | 每次保存都能撤销，每个联系人都能删除，每次提醒都能关闭 |
| 5 | **不制造依赖** | 不催促、不打卡、不用焦虑推动打开 App |
| 6 | **诚实地不知道** | 没把握就说没把握；模型没接通就说没接通；没保存就说没保存 |
| 7 | **谁都能用** | 大字号、读屏、单手、弱网、旧手机都能顺利完成核心流程 |

## 2. 首次使用：30 秒内得到帮助

```text
启动页（品牌 1 秒以内，不做广告）
  → 一屏欢迎：一句话说明「我能帮你什么」+ 隐私一句话 +［开始］
  → 直接进入军师首页（不要求登录、不弹记忆同意、不问 MBTI、不做风格测试）
  → 首页最显眼的是［上传聊天记录］：截图、文件或粘贴
  → 用户第一次得到答案后，再在答案下方温和询问是否保存这个联系人
```

- → 风格小测试不在首次使用时出现。用户导入并确认过一次聊天记录后，App 已经能从中学到风格，此时在「我的风格」页提供入口即可。

- → 欢迎页最多 1 页，不做多页轮播引导。
- → 模型未配置时，首页顶部显示「演示模式」标签，并提供一个不打断操作的入口「接入真实军师」。演示回答必须带有明显的「演示」标识，**不能伪装成真实分析**。
- → 记忆同意在**第一次出现值得记住的信息时**才询问，用一张卡片说明：会记住什么、如何暂停或撤销，并明确「档案保存在这台手机上。分析时，会将本次选中的记忆和脱敏后的聊天样本发送给你配置的模型服务商。你可以查看发送内容，随时暂停或删除本机档案」。按钮使用「好，记住」和「先不用」，两者视觉权重相同，不使用诱导性的默认选项。
- → 用户拒绝后，30 天内不再询问；用户可在「我的」中主动开启。

## 3. 情绪优先：会变化的界面

### 3.1 情绪打分（可选）

输入框上方有一个可收起的「此刻心情」入口，0–10 分滑杆，左右两端文字为「还好」和「快撑不住了」。不使用表情脸，以免显得幼稚或带有评判。

- → 用户不打分也完全不影响使用。
- → 打分随消息一起发送（`emotionLevel`），不单独存档；只有在用户同意记忆时，才作为事件的一部分记录。

### 3.2 平静模式

触发条件（满足任一）：情绪打分 ≥ 8；本地关键词命中高情绪词库（如「想死」「受不了了」「马上分手」「我要骂他」，词库放在 `core/knowledge/src/main/assets/calm-keywords.txt`，可更新）；模型返回 `SAFETY = caution`。

平静模式下：

- → 主题切换为平静配色（见 04 文档的 Calm 令牌），降低饱和度，减少动画。
- → 答案卡只显示「情绪承接」和「现在先做的一件小事」，其余内容收进「等你平静一点再看」。
- → 如果答案中有回复建议，它上方会显示「先别急着发」，并提供「放进草稿箱，10 分钟后再看」按钮。
- → 发送冷静计时器：用户点「复制」时，若处于平静模式，先显示一个可跳过的 10 秒呼吸提示（「深呼吸，确认这是你明天也会想发的话」），提供［还是复制］和［先放草稿］两个按钮。**不得强制阻止用户复制。**

### 3.3 危机安全卡

触发条件：模型返回 `SAFETY = crisis`，或本地关键词命中危机词库（自伤、伤人、家暴、跟踪、性胁迫等）。

- → 在答案区顶部显示安全卡，配色使用沉稳的深蓝，不使用刺眼的红色警报。
- → 卡片内容：一句承接（「你现在的安全最重要，我在这儿」）+ 立即求助方式（110、120 一键拨号，使用 `ACTION_DIAL`，只打开拨号盘，不自动拨出）+「联系一个你信任的人」+ 当地心理援助热线入口。
- → 热线号码以 `references/knowledge/17-中国法律安全与危机转介.md` 为准，统一放在 `core/knowledge` 的资源中；发布前由项目负责人复核号码是否有效，**不得由模型临时生成电话号码**。
- → 危机状态下，不显示任何付费、评分或推进关系的策略内容。
- → 本地检测会误报，因此卡片可以通过「我现在是安全的」收起，收起后仍保留一个小入口。

## 4. 答案卡：一眼就知道该做什么

```text
┌──────────────────────────────────┐
│ [职场·领导] [拒绝] [较正式]  ✎      │  ← SceneChips：军师的判断，点一下就能改
│ 先表态愿意，再说明冲突，给出替代方案   │  ← VERDICT：一句话首选做法（加粗）
├──────────────────────────────────┤
│ 可以这样回                         │  ← REPLY：大字，像你
│ ① 收到王总，这个项目我很想跟。      │     多条消息分开显示，每条可单独复制
│ ② 周六上午我有家里早定好的事，下午   │
│    两点后可以远程处理，您看行吗？    │
│ 更得体 ○──●──○ 更像我              │  ← 风格滑杆
│ [全部复制] [换口吻 ▾] [我发了 ▾]    │  ← 「我发了」展开后有「我改了再发」
│ 备选：更稳妥 · 更直接 ›             │
├──────────────────────────────────┤
│ 💡 本次技巧：先接后转              │  ← TipCard：教会用户，可收藏
│ 先回应对方的需要，再说自己的限制……   │
├──────────────────────────────────┤
│ 为什么是最优 ›   代价 ›             │  （默认折叠）
│ 局势判断 ›      事实 3 · 推测 2 · 未知 1
│ 风险 ›          接下来 ›            │
├──────────────────────────────────┤
│ 想让答案更准？回答 1 个问题：……     │  ← ASK，可点击直接作为下一条输入
└──────────────────────────────────┘
```

- → 「复制」后提示「已复制，去发吧」。不打开其他应用，也不读取剪贴板之外的任何内容。
- → 「换个口吻」选项：更温柔、更俏皮、更直接、更简短、更像我（使用口吻偏好）。仅改写并合并 REPLY／ALT；关联原答案，新操作使用新请求与输入版本，过期结果不得覆盖；检测到危机时提高安全级别并隐藏普通策略。
- → 「我发了」会创建或更新 `ActionPlan`，并询问是否在观察窗口结束时提醒（默认不勾选）。「我没发」同样是正常选项，不带有任何评判。
- → 事实、推测、未知通过**形状和图标**区分，不能只靠颜色（见 04 文档的 EvidenceChip）。
- → 每条事实可以点开查看来源（哪张截图、哪段导入），没有来源的事实标注为「你说的」。
- → 流式生成期间，已经出现的部分可以立即阅读；「停止」按钮始终可见；停止后保留已生成的内容，并标注「未完成」。

## 5. 等待与出错：说人话，不丢东西

| 情况 | 界面表现 | 要求 |
| --- | --- | --- |
| 等待首包 | 三段式进度：「在听你说」→「在理清事实」→「在想怎么办」，伴随狗头呼吸动画 | → 进度文案按时间推进，不伪造百分比 |
| 超过 20 秒 | 追加「有点慢，可能网络不太好。你可以继续等，或者先停下」 | → 不自动取消 |
| 断网 | 正式会话：「网络断开了，已保存加密草稿」；临时会话：「内容暂留本次打开期间，关闭进程后会清除」 | → 正式草稿写加密数据库；临时内容只在进程内存，支持进程存活期间重试 |
| Key 无效或余额不足 | 「模型服务暂时用不了（服务商返回：Key 无效）。去检查设置 ›」 | → 显示真实原因，不笼统写「出错了」 |
| 返回格式不对 | 直接显示全文，顶部标注「这次的回答格式有点乱，内容仍可参考」 | → 不吞掉内容 |
| 内容被服务商拦截 | 「这个问题模型服务商不愿回答。可以换种说法，或者看看求助资源 ›」 | — |
| 切到后台 | 进程存活时可继续；正式会话进程被杀后提示「上次没说完，要继续吗？」；临时会话进程结束即清除 | → 同一操作重试复用 requestId；过期会话／输入版本结果不可写入 |

临时内容（含草稿、导入、截图、摘要、风格样本）不得写数据库、DataStore、文件、SavedStateHandle／Bundle 或后台任务输入。提前说明进程结束即清除；只有用户主动保存联系人会话后才幂等迁移选定内容。

## 6. 记忆：看得见、管得了、能后悔

- → 每次写入记忆后，在答案下方显示一行轻提示：「记下了：小北最近周末加班多 · 撤销」。提示 8 秒后收起，并保留在联系人详情的「记忆」页中。
- → 记忆页按「关于你」「关于 TA」「你们的关系」「关键事件」「军师的猜测」分组，每条都显示来源（你说的 / 来自截图 / 军师推测）和时间。
- → 每条记忆都可以编辑、删除，或标注「这条不对」；被标注的推测会降低置信度或被删除，并且以后不会再以同样的内容写入。
- → 暂停记忆后，首页顶部显示一个小标签「记忆已暂停」，点击即可恢复。
- → 「全部清空」需要二次确认，确认按钮写明具体后果：「删除 3 个联系人、47 条记忆、12 份聊天记录，无法恢复」。

## 7. 提醒：只在用户需要时出现

- → 只有两种通知：用户主动开启的跟进提醒；悬浮军师开启时系统要求的常驻通知。**没有营销推送，没有「好久没来了」召回推送。**
- → 通知文案默认脱敏：「狗头军师：你设的跟进时间到了」，不出现联系人代号和聊天内容。用户可以在设置中改为显示代号。
- → 免打扰时段默认 23:00–08:00，提醒延后到时段结束。
- → 点击通知后进入该联系人的对话，并自动带出：「上次你发了那条消息，对方回了吗？」以及三个快捷操作：「上传新截图」「还没回」「情况变了」。

## 8. 隐私：在别人可能看到你手机的情况下

- → 应用锁：可选生物识别或设备凭据；离开 App 超过设定时间（立即 / 1 分钟 / 5 分钟）后需要重新解锁。
- → 系统交互边界：立即策略仅对用户明确发起的系统 Photo Picker／文档、认证、通知、悬浮设置与投屏，以及同一当前捕获到私密界面的接续，提供从具体 launch 动作起最多30秒且不续期的交接；普通 Home、悬浮球、服务与通知不能创建或刷新该例外。1分钟／5分钟仍用原单调离开期限；取消、失败、超期、熄屏或清除撤销旧事务，旧来源／选择／认证票据不得恢复。只有真实可见的私密 Activity 或 WM 答案／加载／确认面板接续私密 UI；最后私密界面关闭后按原策略锁定。
- → 最近任务预览：开启应用锁后自动对窗口设置 `FLAG_SECURE`，最近任务中不显示内容。该行为在设置中说明（同时会禁止截图）。
- → 伪装图标：通过 `activity-alias` 提供 2–3 个中性的替代图标与名称（如「便签」「计算记录」）。切换前提示桌面图标可能短暂消失。
- → 一键清除：「我的 → 记忆与隐私 → 删除所有数据」，先使会话与请求版本失效，取消网络及提醒，关闭投屏、悬浮窗、服务与通知，再清数据库、文件、缓存、偏好、密钥包装及密钥，回到欢迎页；迟到结果不能重建资料。
- → 正式会话经用户选择保存的截图和文件只在 App 私有目录；临时会话内容与投屏截图只在内存。敏感数据库、文件及密钥排除系统自动云备份与设备迁移；首版仅支持用户主动的加密导出／导入，排除 API Key、投屏授权、临时会话与授权状态，导入后重新询问同意。使用系统 Photo Picker 和文档选择器，不申请读取全部相册或存储的权限。
- → 权限清单只包括：网络、通知（Android 13 以上在开启提醒或悬浮军师时才申请）、生物识别，以及悬浮军师所需的权限（见第 16 节），以及用户主动跟进提醒所需的后台调度普通权限（下表）。这些普通权限不扩大危险数据访问，不授权精确闹钟、营销或召回推送。

| 后台调度普通权限 | 最小用途 | 授权与来源 |
| --- | --- | --- |
| `WAKE_LOCK` | WorkManager 执行短时 CPU 任务 | normal，无运行时授权；选定 `work-runtime:2.12.0` 的实际合并 Manifest |
| `ACCESS_NETWORK_STATE` | 库通用网络状态与约束跟踪；本地提醒不设联网约束 | normal，无运行时授权；同上 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复未取消且来源仍有效的已选一次性提醒 | normal，无运行时授权；同上 |


## 9. 无障碍与适配

- → 所有可点击元素不小于 48×48dp；主要操作位于屏幕下半部分，方便单手使用。
- → 字号跟随系统设置，并在 App 内额外提供「标准 / 大 / 特大」三档（乘以 1.0 / 1.15 / 1.3）；验收系统 200% × App 特大 1.3 的有效 260% 组合，悬浮面板内部可滚动，在该组合下，答案卡、输入区和底部导航都不能被截断。
- → 所有图标按钮都要提供 `contentDescription`；答案卡各分段使用 heading 语义，以便 TalkBack 跳读。
- → 流式输出时，不要让 TalkBack 逐字朗读；生成完成后统一播报「回答好了，可以这样回：……」。
- → 尊重系统的「移除动画」设置。
- → 支持深色模式；横屏和折叠屏下内容宽度最多 640dp，并居中显示。

## 10. 文案口吻

军师的人设：**靠谱的老朋友**。温暖但不黏腻，清醒但不说教，偶尔幽默但不油腻。

| 场景 | ✅ 这样写 | ❌ 不要这样写 |
| --- | --- | --- |
| 空状态 | 「今天遇到什么事了？说说看。」 | 「请输入您的问题」 |
| 记忆同意 | 「档案存在手机上；分析会把选中的记忆和脱敏样本发给你的模型服务商，可查看、暂停或删除。」 | 「为了更好地为您服务，请授权……」 |
| 用户想发火 | 「这口气确实憋得难受。我们先把这条存着，十分钟后再看要不要发。」 | 「请冷静，冲动是魔鬼」 |
| 用户没发消息 | 「没发也是一种选择。想聊聊是什么让你停下的吗？」 | 「您没有执行建议」 |
| 出错 | 「网络断开了；正式会话已存加密草稿，临时会话仅在本次进程内保留。」 | 「错误代码 -1003」 |
| 不确定 | 「这个我没法判断，因为还不知道 TA 那天为什么取消。」 | 「根据分析，TA 可能不喜欢你」 |
| 删除确认 | 「删除后小北的所有记录都会消失，不能恢复。」 | 「确定吗？」 |
| 指出用户的表达问题 | 「你习惯先道歉，这次可以试试先说事情，对方会更快抓住重点。」 | 「你的回复太卑微了」 |
| 职场场景 | 「这样回既接住了任务，也留下了文字依据。」 | 「教你拿捏领导」 |

用词约定：联系人统称「TA」或用户设置的代号；用户称「你」；不使用「亲」「宝」等称呼；不使用「攻略」「拿下」「拿捏」「上岸」等把人当成目标物的词。

## 11. 禁止清单（验收时逐条检查）

- [ ] 首次使用前要求注册或登录
- [ ] 默认勾选记忆同意或提醒
- [ ] 在情绪高或危机状态下出现付费、升级或评分提示
- [ ] 出现「成功率」「爱意指数」「喜欢你的概率」等数字
- [ ] 打卡、连续天数、徽章、排行榜
- [ ] 召回推送或营销推送
- [ ] 通知中默认出现联系人代号或聊天原文
- [ ] 悬浮军师在用户没有点击时自动截屏或自动分析
- [ ] 使用无障碍服务读取其他应用，或自动向其他应用填入、发送文字
- [ ] 演示模式的回答没有标注「演示」
- [ ] 进程存活期间的失败丢失输入，或正式会话无法恢复加密草稿；临时会话结束未明确告知清除
- [ ] 只用颜色区分事实、推测和未知
- [ ] 未经用户确认说话人就开始分析
- [ ] 截图被上传；或者未脱敏的手机号、证件号被发送给模型
- [ ] 提供诬陷、甩锅、伪造聊天记录、冒充他人、操控他人的方法
- [ ] 用嘲笑或贬低的语气指出用户的表达问题

## 12. 导入聊天记录：少一步是一步

用户导入时往往很急，而且截图里有别人的隐私。

- → 首页「上传聊天记录」点开后直接是三个选项：截图（默认打开 Photo Picker，可多选）、文件、粘贴。不出现中间说明页。
- → 在微信等应用中长按文字或图片，选择分享到「狗头军师」，可以直接进入导入流程。
- → 说话人确认只问一次：「右边是你吗？」［是］［不是，左边是我］。推断正确时，用户只需点一下。
- → 识别结果以聊天气泡的形式预览，与原截图的样子接近，方便核对；置信度低的文字用虚线下划线标出，点击即可修改。
- → 预览页底部有一行「将向所选模型服务商发送本次选中的聊天、记忆与样本；已隐藏可识别的个人信息，可能漏检 · 查看／添加屏蔽词 ›」，发送前披露提供方和范围，允许检查；预览与主分析、摘要、风格描述、改写及对练的实际请求使用同一出站组装结果，对全部字段统一脱敏。
- → 首次导入时提示一次：「请只上传你有权使用的聊天内容。图片只在手机上识别，不会上传。」

## 13. 风格：像你，但更好

- → 风格画像对用户是透明的：「我的风格」页用白话描述，例如「你常用『哈哈』开头，喜欢用短句，很少用句号，对领导会用『您』」，而不是显示一堆数字。
- → 用户可以直接编辑描述，也可以删除任何一条样本。导入、测验、修改回复及全部派生画像统一受当前同意／暂停／撤回门禁控制，未获准仅在当前会话内存使用；异步返回重新检查授权版本。
- → 样本显示来源，删除联系人、导入或样本时删除关联样本，使画像、提示词及摘要缓存失效并按剩余样本重算；全局风格不能作为其他联系人的事实记忆。
- → 生成的回复如果明显不同于用户的习惯（例如用户从不用 emoji，但对暧昧对象这次建议用了），在回复下方用一行小字说明原因：「这次加了一个表情，能让语气轻松一点，不喜欢可以去掉」。
- → 「更得体 ↔ 更像我」滑杆在不同关系大类中分别记住用户的选择。

## 14. 教学：让用户越用越会

- → 每次回答最多一个技巧点拨，不要一次教很多。
- → 技巧点拨要和本次回复对应：说明这个技巧在回复中的哪一句体现出来。
- → 表达习惯提醒（HABIT）每个联系人每天最多一次，并且总是先肯定再建议；用户可以选择「不再提醒这一条」。
- → 对练中的点评只有一行，并附上一个更好的版本；在用户连续进步时给予具体的肯定（「这次你先回应了 TA 的情绪，很好」），而不是泛泛的「真棒」。
- → 技巧本是用户主动收藏的内容，不做学习进度、等级或打卡。

## 15. 不同场景的人性化差异

| 场景 | 特别注意 |
| --- | --- |
| 职场 | 用户可能在上班时间、在工位上使用：答案要短，首屏就能复制；回复默认符合书面沟通的要求；提醒书面留痕；遇到职场欺凌、性骚扰、违法要求时，给出保护自己的做法和正式渠道，不只教怎么回话 |
| 亲密 | 沿用 Skill 的全部原则；不预设性别角色；明确拒绝时停止推进 |
| 家庭 | 承认亲情中的复杂感受（爱和委屈可以同时存在）；不默认「听父母的」，也不默认「断绝关系」；涉及家暴时转入安全流程 |
| 调解 | 用户作为第三方时，提醒他不必承担解决所有问题的责任；不建议在双方之间传话时添加内容；给出「什么时候该退出调解」 |
| 群聊 | 提醒群聊消息会被很多人看到、可能被截图转发；敏感内容建议私聊 |

## 16. 悬浮军师：就在聊天旁边，但不打扰

悬浮军师让用户不离开微信等聊天应用，点一下就能拿到建议。它出现在别的应用上面，所以要比 App 本身**更克制**。

### 16.1 行为原则

- → **只在用户点击时截屏**。悬浮球不会自动截屏、不会自动分析、不会主动弹出建议。
- → **只复制，不代发**。不向其他应用填入文字，不代替用户发送。
- → **看得见的状态**：会话有效时悬浮球显示待命（半透明停靠）或分析中（呼吸动画）；会话停止后移除悬浮窗、服务和通知，在 App 或磁贴重开并重新授权。屏幕录制授权有效期间，系统会在状态栏显示录屏标识；首次开启时要向用户说明这一点：「开启期间状态栏会显示录屏图标，这是系统的提示。我只在你点击悬浮球时看一眼屏幕。」
- → **不挡视线**：面板最多占屏幕的 55%，可以往下拖小，内容内部滚动以保证最高字号组合下所有操作可达；复制后自动收起；在屏幕边缘停靠时只露出一半。
- → **随时能关**：长按悬浮球 →「关闭悬浮军师」；常驻通知中也有关闭按钮；快捷设置磁贴可以一键开关。
- → **自动收工**：10 分钟未使用、系统停止、锁屏、撤销或主动关闭均清理捕获资源及旧帧，关闭悬浮窗、FGS 和通知；通过 App 或磁贴新授权重开。

### 16.2 首次开启流程

```text
「我的」或首页 → 开启悬浮军师
  → 一页说明：能做什么 / 只在你点击时看屏幕 / 图片不上传 / 状态栏会显示录屏图标
  → 授予悬浮窗权限（跳转到系统设置，返回后自动检查）
  → 按机型显示的后台运行引导（可以跳过，跳过后在出现问题时再提示）
  → 系统录屏授权弹窗（Android 14 以上建议选择「单个应用」并选择聊天应用）
  → 悬浮球出现，旁边显示一次提示气泡：「打开一个聊天，点我试试」
```

- → 每个步骤都可以返回，任何一步被拒绝都不影响 App 的其他功能，只是悬浮军师不可用，并提示可以改用「截图后上传」。

### 16.3 面板中的人性化细节

- → 面板顶部始终显示当前联系人和场景标签，避免用户把给领导的回复发给了别人。用户在不同的聊天之间切换后，昵称只能提供候选；新映射、同名、缺标题、群聊或来源冲突时先确认身份，确认前不读取候选记忆。来源应用或账号不可靠时让用户确认来源或每次确认联系人；不能用昵称作为唯一键。
- → 识别到情绪激烈或危机信号时，面板同样切换为平静模式或显示安全卡，规则与 App 内一致。
- → 无有效画面时提示「暂时没能读取画面」，可检查共享应用或重试；纯黑不能判断禁止截图。确认受保护时提示「这个页面限制了截图，可以手动复制可分享的文字，或导入你已有的聊天文件」。不绕过保护，纯黑帧不送模型。
- → 在公共场合使用时，面板不显示联系人的真实昵称，只显示用户设置的代号。

### 16.4 新增权限（仅在开启悬浮军师时申请）

| 权限 | 用途 | 拒绝后 |
| --- | --- | --- |
| 悬浮窗（`SYSTEM_ALERT_WINDOW`） | 显示悬浮球和面板 | 悬浮军师不可用，其他功能正常 |
| 屏幕录制授权（MediaProjection，每次会话由系统弹窗确认） | 用户点击时截取一帧 | 同上 |
| 前台服务（`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PROJECTION`） | 系统要求屏幕录制必须在前台服务中进行 | — |
| 通知（Android 13 及以上） | 显示常驻通知 | 系统可能不显示通知，但服务仍需运行；在说明页中提示 |

**不申请**：无障碍服务、使用情况访问权限（`PACKAGE_USAGE_STATS`）、读取全部相册或存储。
