# T34 · 权限与机型引导

本包基于 T33 `b91a7e85abdf1f57c80b560ce18ff2d64c44a19e`。新增功能性指南，视觉精修与三品牌真机验收仍由负责人完成。

## 产品流程与权限

每次用户明确开启，先显示一页用途、点击才读取、图片不上传与录屏状态说明；可以取消。悬浮窗权限缺失时显示设置入口，使用 `ACTION_MANAGE_OVERLAY_PERMISSION`，返回后重新检查。Android11+可能先进入设置应用列表，说明页提示先选狗头军师，再开启权限。授权后展示可跳过的机型后台指南，再请求 Android 13+ 通知权限。通知拒绝后停留在解释页，只有明确点击继续才申请系统录屏；不重复弹通知权限，不把通知许可作为录屏的额外准入门禁。服务仍按系统要求提供前台服务通知。

后台指南也可通过“悬浮球消失了？查看机型指南”再次进入；仅浏览、设置和退出，不启动录屏。单应用共享只在系统提供该项时建议用户选择聊天应用（Android 14 QPR2+部分系统），不按所有 API34 设备必然可用处理，也不代替用户选择共享范围。

## 机型与设置降级

仅使用 Build.MANUFACTURER / BRAND，经去空格和大小写规范化识别 Xiaomi / Redmi / POCO、Huawei、Honor、OPPO、OnePlus、vivo / iQOO；其他品牌展示通用步骤。Honor、OnePlus 的子品牌优先于母品牌。步骤含本应用悬浮窗、后台活动、自启动及电池管理；说明版本与地区差异，不要求关闭全局省电。

没有证实稳定且可安全启动的厂商 component，因此首版不猜测私有组件。设置入口先 resolve，启动或解析异常时退到本应用系统详情页；详情不可用时保留手动步骤。Launcher 接受安全候选的测试覆盖无法解析、启动异常、解析异常及最终失败。不新增 QUERY_ALL_PACKAGES、UsageStats、Accessibility、全图库或 REQUEST_IGNORE_BATTERY_OPTIMIZATIONS 权限。

## 生命周期与安全

说明、设置返回、通知结果和明确继续使用同一个 RAM ticket / lockRevision。替换请求、停止、锁版本改变、取消或销毁后旧结果不能开启投屏；重建不恢复 ticket 或 grant。通知回调绑定原始请求身份；投屏使用每次不同的 requestCode，防止同 Activity 的旧 A 结果接上新 B。投屏 Intent 不交给 ActivityResultRegistry 保存。

CAPTURE_CONFIRM 仍优先匹配原 preview / ticket / 当前 receiver，UNLOCK 仍要求设备凭据；磁贴交接仅使用有效 ticket 进入说明。截图的单 VD、按点击更新 Surface、Paddle 隔离无网络且无统计、内存临时数据、知识库→脱敏→冻结实际正文预览→同来源配置版本锁等链路继续沿用 T31–T33 / T43。

## 安装与商店介绍限制

HarmonyOS NEXT（纯血鸿蒙）无法安装 Android APK。安装说明、官网及应用商店介绍应明确此限制；本 Android App 不做运行探测或展示无意义阻断。普通 HarmonyOS 的安卓兼容版本与 NEXT 应区分。鸿蒙原生版不在本工作包。
