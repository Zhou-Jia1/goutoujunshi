# T25 场景识别与完整答案卡

本包接入现有文字分享、确认聊天证据与手输路径。OCR T22 的 SDK 决策和截图输入集成门禁尚未通过；本包不宣称 T22 或完整 M2 验收。所有测试数据均为虚构，没有真实 Key、外网模型调用或品牌真机验收。

本地关键词预测只读取用户输入和已确认的证据行；联系人关系优先，显式选择优先于本地预测。模型 SCENE 提供最终场景，手动选择不会被本地预判覆盖。SceneChips 支持修改关系、目标和正式程度，并发起新 FULL_ANALYSIS。

生产答案按场景、结论、多消息回复、操作、折叠详情呈现。每条及全部复制沿用敏感剪贴板标记。ALT、WHY、COST、SITUATION、FACTS/GUESSES/UNKNOWNS、RISK、NEXT 折叠；证据复用 DS EvidenceChip 的文字标签、符号与边框，颜色只是辅助。每条事实可从当前联系人、相同来源版本的已确认行打开本地来源片段；无引用标“你说的”，未知、跨联系人或失效引用标“来源暂不可用”，不显示机器ID、不查询其他联系人。推测保留低/中/高置信度文字，读屏可读取。答案没有可追溯 assistant 来源时使用只读详情，不提供需要来源的场景编辑、改写或反馈操作。

换口吻和风格确认发新 REWRITE_REPLY，关联 parentAnswerId，更新 inputRevision，并保存原答案快照。只合并 REPLY/ALT；新版本有独立答案 ID，历史助手消息不被覆盖。每个 LIVE 新操作均重新准备实际完整发送预览，确认后才发送；Demo 使用本地示例，保留演示标记且不联网。统一使用 FrozenPromptAssembler、真实 canonical KB、T23 隐私门禁及 CompletionBody；T24 配置/Key/revision 和 T27 安全检查点与仅存储重试继续生效。

“我发了”必须经用户主动确认才记 SENT；“我改了再发”打开仅 RAM 编辑框，确认保存为 PENDING 修改版本，不声称已经发送，不启动外部消息应用。正式版本经现有加密 PLAN 记录保存；临时版本只进入 TemporarySessionStore。记录包含 assistant 消息来源、request、会话/输入/联系人来源版本、当前 consentVersion、wasEdited，learningAuthorized 始终为 false。不同修改按内容哈希保留版本，相同操作重试幂等；写入失败不显示已保存，重试只修复存储。这里保存用户选择与明确来源，不创建 StyleSample、不自动同意学习；T41 统一授权和来源门禁仍须独立实现。

数据事务检查联系人来源、会话版本、隐私规则版本和真实 assistant 所属，不能重建删除的联系人。控制器按 origin/答案 ID 拒绝旧事件；输入、来源、隐私和配置变化使原操作失效。锁定先阻敏感页；最高安全级别只升级，CRISIS 隐藏普通策略、复制、编辑与反馈，复用现有 DS SafetyCard，没有新增热线或扩大 T53 范围。

DS 新增 ReplyEditField：复用状态版 OutlinedTextField，使用进程内 TextFieldState 和 2–6 行有界布局，支持滚动对话框内的大字号编辑。没有新增视觉令牌。新增页面只组合已有 SceneChips、ReplySuggestionCard、AnswerActionBar、StyleBalanceSlider、CollapsibleSection、EvidenceChip、FormTextField、ContentDialog 、SafetyCard 和 ReplyEditField；所有新增界面文案进入 strings.xml，视觉精修留给 Claude。
