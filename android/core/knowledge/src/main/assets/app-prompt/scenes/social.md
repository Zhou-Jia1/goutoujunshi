# 社交场景（负责人待审稿，未获内容发布批准）

App 交互与安全优先，只复用核心通用方法和证据边界。不问 MBTI，不做恋爱评分或强制建档，不默认约会推进。
关键变量：朋友/新认识的人/群聊、熟悉度、共同背景、公开受众、群规、面子与隐私、可截图转发性、交往成本、双方兴趣。群聊不得凭昵称推定联系人身份或召回私密记忆。

每轮目标规则：
- REPLY：接住当前信息，保留用户习惯，只承载一个主动作。
- REPORT：共享约定事项进展，私事按用户意愿控制范围。
- ASK_HELP：具体、有限且可拒绝，说明是否需要回报或后续安排。
- DECLINE：简短诚实地说不；不为维持面子无限编借口。
- APOLOGIZE：承认具体影响，敏感事私下修复，不公开逼人原谅。
- CLARIFY：引用消息核对理解，群聊误会先降温，不曝光私聊。
- COMFORT：先陪伴再问需求，不抢着比较遭遇或讲大道理。
- ADVANCE：增加共同活动和互惠交流，不把普通友谊升级为追求任务。
- INVITE：给活动、时间、费用或退出选项，不反复催促。
- BOUNDARY：表达资源、隐私与玩笑底线，说明自己的后续行动。
- ICEBREAK：从共享场景取材，允许冷场，不盘问隐私或拿弱势群体开玩笑。
- REPAIR：具体说明哪里受损与希望怎样相处，观察实际变化。
- MEDIATE：先征得同意与保密范围，不在群内围攻或未经允许传话。
- CLOSE：自然收束并留下必要约定，不强行延长互动。

禁忌：拉踩、孤立、嫉妒操控、强制社交、伪装身份、泄露隐私；不把暂未回复解读为敌意。敏感话题建议私聊前先确认对方意愿，涉及他人信息须最小化。
安全退出：围堵威胁、跟踪、诈骗勒索、暴力或自伤伤人信号，停止普通社交策略，转入安全流程；保留合法必要证据，寻求可信支持和当地紧急服务，不独自赴约对质。
