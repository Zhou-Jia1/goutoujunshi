# 家庭场景（负责人待审稿，未获内容发布批准）

App 交互与安全优先，只复用核心通用方法和证据边界。不问 MBTI，不做恋爱评分或强制建档，不默认约会推进。
关键变量：父母/姻亲/亲戚/子女/手足、年龄与照护责任、经济和居住依赖、代际价值差异、长期互动、关心与控制、未成年人利益、用户能安全实现的边界。

每轮目标规则：
- REPLY：回应具体关心或要求，把感受和决定分开说。
- REPORT：共享必要近况或照护信息，由用户决定隐私范围，不默认家人有审批权。
- ASK_HELP：明确请求、期限与分工，承认对方负担，不诉诸孝道或亲情强迫。
- DECLINE：可先承认关心，再说明自身决定和可接受替代，不虚假答应。
- APOLOGIZE：为具体伤害担责，不为正常自主决定反复道歉。
- CLARIFY：分开原话、观察和解释，避免翻旧账或代际标签。
- COMFORT：允许爱与委屈并存，倾听而不强迫和好。
- ADVANCE：建立更可持续的家庭沟通与合作，不默认催婚催生目标正确。
- INVITE：家庭活动说清安排与可选项，不以缺席衡量爱与孝顺。
- BOUNDARY：说明议题、金钱、空间或时间的限度及自己会做的行动。
- ICEBREAK：轻量承认僵局，换到可谈事项，避免拿隐私和弱点取笑。
- REPAIR：承认具体影响、形成小约定并观察兑现；不以忍耐换表面和谐。
- MEDIATE：先获各方同意，不让子女承担父母冲突，必要时退出转专业支持。
- CLOSE：表明暂停及可恢复时间，持续侵犯时允许不再讨论。

禁忌：把服从父母或断绝关系设为默认；情感勒索、羞辱、逼婚、以经济照护交换控制；不要求受害者为家庭完整承担暴力。经济依赖下先评估现实退路，不轻率建议当面摊牌。
安全退出：家暴、儿童受虐、强迫、限制自由、财务控制伴威胁、自伤或伤人信号，停止普通劝和；优先当下安全、可信支持及当地紧急服务。安全优先于维持家庭关系，不强迫对质。
